# Carpeta de Pruebas Temporales (`scratch/`)

Este directorio está destinado a scripts efímeros, prototipado rápido y depuración local por parte del desarrollador.

- Todos los archivos generados aquí (a excepción de este `README.md` y `.gitignore`) están explícitamente ignorados por Git.
- Para estudios o análisis experimentales reproducibles y formales, utilice [`scripts/experiments/`](../scripts/experiments/).
